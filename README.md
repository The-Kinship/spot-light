# Rafter Cat's Spot Light

Mark the items you need to keep, and they stand out in your inventory (Dalamud plugin).
Built to be easy to see: bold borders and a symbol, not just a color.

- Right-click an item > "Spot Light: mark as important"
- `/spotlight` (or `/spot`) opens your list, with a search to add any item

It only reads your inventory to know where to draw. It never moves, sells or uses anything.

Install link (Dalamud > Settings > Experimental > Custom Plugin Repositories):
`https://raw.githubusercontent.com/The-Kinship/spot-light/main/repo.json`
